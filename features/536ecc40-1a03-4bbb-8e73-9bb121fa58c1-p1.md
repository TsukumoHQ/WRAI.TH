# Decision — Phase 1 referential-integrity reconcile (task 536ecc40)

ROOT_CAUSE: After Phase 0 (detect+log+quarantine, merged f2f48c0), the relay has
a full inventory of dangling identity references but has HEALED none of them —
the ~500+ orphans and 14 limbo tasks are surfaced yet still broken. The
mechanically-resolvable subset (a task assigned to a profile SLUG that maps
unambiguously to one live agent; a task profile_slug stale relative to its live
assignee) can be corrected automatically; the rest cannot be resolved without
inventing history or rerouting live work.

DECISION: Ship Phase 1 (design §6, ruled by cto-tsukumo). A one-shot,
settings-marker-guarded (reconcile_orphans_v1), snapshot-backed reconcile that
HEALS the resolvable orphans and leaves the rest MARKED — never deletes, never
reroutes. Runs from New() (post-migrate, pre-serving) because the pre-mutation
snapshot needs *DB.

Two reconcile rules (nothing else auto-changed):
- Rule A: sync a stale task.profile_slug to its LIVE assignee's own profile
  (reuses the existing, tested backfillTaskProfileSlugs T3 rule).
- Rule B: an ORPHAN task.assigned_to whose value is a profile SLUG with EXACTLY
  ONE active agent of that profile in the project -> resolve to that agent's
  NAME. Fixes the name-vs-slug misroute (the audit's analytics-lead class) by
  making the task claimable by the one live agent that runs the profile.

Left MARKED as unresolvable (per ruling): structural profile_slug orphans (never
rewritten to a name — Q5, profile_slug is the profile-pool key); dispatched_by /
claimed_by (a historical record — resolving them would fabricate history); limbo
(reassigning a dead-assignee task to another agent is a REROUTE, forbidden — it
stays surfaced for human/CTO triage); sentinels {linear,cron,user}.

Safety: a dedicated VACUUM INTO snapshot (throwaway read-only conn, never the
writer pool — Backup() discipline) is taken BEFORE any mutation; if it fails,
nothing is mutated and the marker stays unset (retry next boot). Each rule is
independently idempotent (its WHERE stops matching once the row is healed), so a
crash mid-pass is safe. Non-fatal: a reconcile error never blocks the relay from
booting. After the reconcile a re-scan stamps the healed quarantine rows
resolved (audit trail, not deleted).

REJECTED ALTERNATIVE: canonicalize a profile-slug dispatch target at WRITE time
(DispatchTask). Rejected by ruling Q5 — profile_slug is the pool key and the
write-sites already store resolveAgent names/sentinels (nothing to canonicalize).
Phase 1 only backfills EXISTING orphan DATA, it adds no write-site rewrite.

REJECTED ALTERNATIVE: resolve ambiguous slugs (>1 live agent) by picking one, or
reroute limbo tasks to a live agent of the same profile. Rejected — both are
guesses/reroutes the ruling forbids; ambiguous + limbo stay marked for triage.

REJECTED ALTERNATIVE: rewrite dispatched_by orphans to a sole-live-agent name.
Rejected — dispatched_by is the historical fact of who dispatched; rewriting it
to a different current agent fabricates provenance. Only assigned_to (routing-
relevant) is healed.
