## 2. Root cause & decisions

# Decision — bb541360: batch MarkDeliveriesSurfaced (R3) + nest session registry (R5)

ROOT_CAUSE:
- R3: `MarkDeliveriesSurfaced` (deliveries.go) looped K single-row `UPDATE ... WHERE id=?`
  statements. Each Exec grabs the single sqlite write-lock, so surfacing an inbox read fired
  a lock storm proportional to inbox size on the read path.
- R5: `SessionRegistry.sessions` was a flat `map["project:agent"][]sessionID`. `AgentForSession`
  (run on EVERY guarded write, in guardIdentity) and `NotifyBroadcast` scanned the WHOLE map
  with `strings.HasPrefix(key, project+":")` — O(all sessions across all projects) per call.

## Decision
- R3: one `UPDATE deliveries SET state='surfaced', surfaced_at=? WHERE state='queued' AND id IN (…)`
  per batch, chunked at 900 ids to stay under SQLite's host-parameter cap (SQLITE_MAX_VARIABLE_NUMBER).
  One lock acquisition per batch instead of K. Identical semantics (only queued→surfaced).
- R5: nest the map `project → agentName → []sessionID`. `AgentForSession`/`NotifyBroadcast` now
  iterate only `r.sessions[project]` (O(agents-in-project)); `Register`/`Notify` are direct
  two-level lookups. `Unregister` still scans (it is keyed only by session id — an agent may
  hold sessions across projects — and runs on disconnect, never on the hot write path).
  `registryKey` + the `strings` import are removed. Behaviour unchanged: same agent resolved,
  same >1-agent ambiguity fail-open, same cross-project isolation.

## Rejected alternatives
- R5 reverse index (sessionID → {project:agent} set): O(1) but adds a second structure to keep
  in lockstep on every register/unregister; the AC prescribes nesting, which is simpler and
  contained to notify.go.
- R3 one tx wrapping the K UPDATEs (the AC's alternative): a single IN-list UPDATE is fewer
  statements AND one lock, strictly better than a tx of K statements.

## Scope
deliveries.go (MarkDeliveriesSurfaced) + notify.go (SessionRegistry) + tests. No schema change,
no sqlite writer/lock-config change, no HTTP/MCP surface change.
